# Compliance Theater MCP Resources

This MCP server exposes its bundled agent guidance as file resources. Read the skill files below when a task matches their scope.

- [Compliance Theater](.agents/skills/compliance-theater/SKILL.md) - education compliance case-file, policy, evidence, memory, and workspace tasks.
- [Compliance Theater Workspace](.agents/skills/compliance-theater-workspace/SKILL.md) - local evidence workspace organization, investigation artifacts, and workspace-specific workflows.
- [Neo4j Graph Data](.agents/skills/neo4j-graph-data/SKILL.md) - graph schema inspection, relationship traversal, and Neo4j-backed evidence work.
- [Record Investigation](.agents/skills/record-investigation/SKILL.md) - record correction, evidence enrichment, and investigation support.

Reference files are available under each skill's `references/` folder, and model-specific agent files are available under each skill's `agents/` folder.
